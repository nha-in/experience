Shared by the desktop rail and the mobile drawer so the two never drift. Every product link points at `current_product` (abdm.context_processors): the product this person last opened, or the organisation's first. With no product registered yet the rail offers the registration step instead. Boosted: htmx fetches the very URL each href already points at, keeps only #main-content out of the whole-page response and swaps it in, and picks this nav out of the same response out-of-band so the active item follows the page. hx-push-url keeps the address bar and the back button honest. With JavaScript off every link below is still a plain . Each link carries an id because the out-of-band swap replaces this whole nav, destroying the very anchor that was activated: htmx puts keyboard focus back on the element with the same id.
