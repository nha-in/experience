Boosted: htmx fetches the very URL each href already points at, keeps only #main-content out of the whole-page response and swaps it in, and picks this nav out of the same response out-of-band so the active item follows the page. hx-push-url keeps the address bar and the back button honest. Nothing about this needs a view to know it happened. With JavaScript off every link below is still a plain and the browser navigates normally, which is the path that has to keep working. Each link carries an id because the out-of-band swap replaces this whole nav, destroying the very anchor that was activated: htmx puts keyboard focus back on the element with the same id, and without one focus falls to and a keyboard or screen-reader user is dropped at the top of the document. {% endcomment %} {% load i18n %}
